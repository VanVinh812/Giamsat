⚙️ Kết nối Database
Để dữ liệu điểm danh đồng bộ giữa tất cả thành viên, cần kết nối Google Apps Script. Làm theo các bước dưới đây (chỉ cần làm 1 lần).
Bước 1 — Mở Google Apps Script

Vào script.google.com → nhấn New Project

Bước 2 — Dán code backend

Xóa code mặc định → Dán toàn bộ nội dung file apps-script.js đã tải về → Nhấn 💾 Save

Bước 3 — Deploy

Nhấn Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Deploy → Copy URL

Bước 4 — Dán URL vào đây

Dán URL Web App vừa copy vào ô bên dưới
